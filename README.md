# ☕ Bootcamp Santander — Java

Exercícios e desafio de código feitos durante o **Bootcamp Santander (DIO)**, praticando os fundamentos de Java.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## 📂 Conteúdo

| Pasta | O que faz |
|---|---|
| [`Aula1`](Aula1/src/App.java) | Primeiro programa: lê nome e idade pelo terminal com `Scanner` e exibe uma saudação. |
| [`Aula2`](Aula2/src/App.java) | Verificador de idade: calcula a idade pelo ano de nascimento e diz se a pessoa pode dirigir. |
| [`ContaBanco`](ContaBanco/src/ContaTerminal.java) | **Desafio do bootcamp:** coleta número da conta, agência, nome e saldo, e exibe a mensagem de conta criada. |

## ▶️ Como executar

```bash
cd ContaBanco/src
javac ContaTerminal.java
java ContaTerminal
```

## 🧠 Conceitos praticados

- Entrada de dados com `Scanner`
- Tipos primitivos, `var` e `String`
- Condicionais (`if/else`)
- Formatação de saída com `printf`
